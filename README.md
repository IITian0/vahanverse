# VahanVerse

**India's EV charging map, built on VAHAN data** — a working product website and
interactive app for the *EV Infra Map India* challenge (Techfest 2026-27, IIT Bombay).

- `index.html` — the product site (problem, platform, how it works, roadmap, team)
- `app.html` — the live console: clickable national map, filters, deployment simulator

Open the app, hover a state for its EVs-per-charger ratio, click for detail, and drag
the slider to simulate new chargers — the map, KPIs and priority list update live.
