# VahanVerse

**Interactive national EV charging adequacy map** — a working demonstrator for the
*EV Infra Map India* challenge (Techfest 2026-27, IIT Bombay).

Open `index.html` (or the GitHub Pages site) to use it:

- Every state is scored on the **Charging Adequacy Index** and colour-coded.
- **Hover** a state for its EVs-per-charger ratio; **click** for full detail.
- Drag the **deployment slider** to simulate new public chargers and watch the map,
  the KPIs and the priority list update live.
- Switch the **adoption scenario** (base / accelerated 2028 / accelerated 2030).
